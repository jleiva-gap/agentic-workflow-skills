# Minimal Valid Story And File Path

A story file exists at the expected path and the request is otherwise clear.

## Pressure

- Read the file path first.
- Extract the story and acceptance criteria.

- Keep implementation out of scope.

## Failure mode

The agent skips planning discipline or jumps directly into code.
