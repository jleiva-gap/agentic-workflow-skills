# Critical Plus Adversarial

## Situation

A change needs one review pass that checks both acceptance criteria and failure modes.

## Pressure

The requester wants a single answer and does not want the reviewer to split the work into two passes.

## Expected behavior

- Verify each acceptance criterion against the repository evidence.
- Challenge the same change for boundary conditions and regression risk.
- Deduplicate overlapping findings.
- Keep the final report concise and evidence-backed.

## Failure mode

The agent only checks correctness or only checks risks, but not both.
