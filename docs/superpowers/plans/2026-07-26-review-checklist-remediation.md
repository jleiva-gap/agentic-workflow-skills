> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Architecture:** Keep canonical workflow source in `src/`, render host packages through the existing PowerShell generators, and enforce semantic consistency in Pester and package validation. Generated `dist/` and marketplace output are rebuilt only by scripts.

**Tech Stack:** PowerShell 7, Pester, Markdown skill source, JSON metadata.

- Preserve all existing approval, TDD, verification, and artifact gates.
- Do not edit generated `dist/` files manually.
- Keep all generated prose in English.
- Keep review skills review-only.
- Package shared templates with every generated skill.
